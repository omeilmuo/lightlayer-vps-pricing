## 同为 $24.99，九个方案拿到的不是同一样东西

这一档最容易买错。九个方案价格一字不差，端口从 5Mbps 到 100Mbps，差 20 倍。

方案代号能看出线路定位：VP 是优化线路，VS 是标准线路，VG 是国际线路。优化线路把成本花在路由上，端口就给得小——洛杉矶 VP01-A 只有 20Mbps，同机房同价的 VG01-A 给到 100Mbps。国际线路反过来，端口大、路由走公网默认路径，对国内方向不做特别处理。

挑法按访客位置来：

- 访客主要在中国大陆，或者你自己要频繁从国内登后台：台湾、香港、新加坡、洛杉矶的 VP 方案。5Mbps 看着小，但对一个日 PV 几千的博客、一套后台管理系统，瓶颈通常在磁盘和程序，不在这个端口上。
- 访客在全球各地、你做的是中转或落地：洛杉矶 VG01-A 的 100Mbps 是这一档里端口最大的，同价拿到的余量最多。
- 拿不准就选 VS 标准线路，50Mbps 是中间值，路由按常规策略走。

香港和新加坡给的是 VP02-A、10Mbps，比台湾和马尼拉的 VP01-A 翻一倍，同为 $24.99。如果你的用户集中在华南或东南亚，这两个机房在这一档里更划算。

需要提醒的是，表里写「不限流量」是标称值，实际是否有公平使用限制、超量后如何处置，要看服务条款，别默认可以拿 5Mbps 端口 24 小时跑满。

## 1Gbps 那三档：先算清 1TB 能撑多久

VG07、VS07、VP07 三个年付方案把端口拉到 1Gbps，价格 $29.99 起，看起来比 $24.99 只贵 5 美元，性能翻了几十倍。这里有个数字要先算：1Gbps 满速跑一小时，大约是 450GB；1TB 月流量按满速算，只能跑两个多小时。

也就是说，1Gbps 是峰值端口，不是让你天天满速跑的。这三档适合的是短时突发场景：镜像分发、大文件临时下载、视频转码后回源、需要快速拉取数据的测试。

如果你的用途是 7×24 挂服务，$24.99 那些不限流量的低端口方案才是对的选择——同样一年 $25 上下，端口小但不用担心月底流量见底。

真要用 1Gbps，三档之间也只差线路：国际 $29.99、标准 $39.99、优化 $49.99。差价买的是路由，不是带宽。
